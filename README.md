# BeepPlayer-Afterglow
A modified version of [AlexGuo1998/BeepPlayer](https://github.com/BillZhou233Cute/BeepPlayer-Afterglow) to work with Afterglow OS

## Usage

- To compile

```bash
cd src
make
```

- To play

```bash
sudo ./bp path/to/song.txt
```
